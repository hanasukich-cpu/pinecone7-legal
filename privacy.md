Privacy Policy for Pinecone 7

Last Updated: June 2026

This Privacy Policy explains how Pinecone 7 collects, uses, and stores information when users interact with the bot.

Information Collected

Pinecone 7 may collect and store:

- Discord User IDs
- Discord Server (Guild) IDs
- Discord Channel IDs
- Discord Role IDs
- Command usage logs
- Server-specific configuration data
- Publicly available data retrieved from third-party services used by the bot

Message Content

Pinecone 7 may process message content when necessary to execute commands or provide functionality. Message content is not stored by the bot.

Purpose of Collection

Information is collected solely to:

- Provide bot functionality
- Process commands
- Store server settings and configurations
- Maintain service reliability
- Diagnose issues and improve functionality
- Monitor command usage and performance

Data Retention

Data is retained only for as long as necessary to operate and maintain Pinecone 7. Data may be deleted periodically when no longer required.

Data Sharing

Pinecone 7 does not sell, rent, or share user data with third parties except when required by law.

Security

Reasonable measures are taken to protect stored information. However, no method of electronic storage is completely secure.

Data Deletion Requests

Users or server administrators may request deletion of applicable stored data through the Pinecone 7 Support Server.

Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of Pinecone 7 constitutes acceptance of any revised policy.
